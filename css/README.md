# E-commerce

Proyecto final de JavaScript de Coderhouse.

La página permite ver y buscar productos, agregarlos al carrito, modificar cantidades, eliminar productos y simular una compra.

Los productos se cargan desde un archivo JSON mediante `fetch`. Se utiliza `localStorage` para guardar los productos y el carrito.

## Tecnologías

- HTML
- CSS
- JavaScript
- JSON
- SweetAlert2
- Toastify
